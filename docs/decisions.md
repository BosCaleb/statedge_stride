# Decisions and deviations from the specification

Every place where the build differs from, or adds to, `docs/spec.md`, with the reason. Entries marked **Needs approval** add a dependency or service the specification does not name, or change a stated choice; they stay as built until StatEdge says otherwise. Entries StatEdge has decided say so, with the date.

## Measured in the spike (M0)

See `docs/spike-report.md` for the numbers behind these provisional choices: WebCodecs with the video-element fallback, a module worker, the full model with the GPU delegate and CPU fallback, a 256 by 144 stability signature, and low-pass cut-offs of 16 Hz (distance) and 25 Hz (sprint). The on-device measurements on the S23 Ultra are still to be made.
