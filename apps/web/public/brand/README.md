# StatEdge brand assets

Supplied by StatEdge for the Stride application. `statedge-icon.png` is the web-sized
icon from the supplied `statedge-loader` folder (the same mark as the large print
export). The two wordmarks are the supplied transparent apparel/full-colour PNGs,
used against dark and light surfaces respectively. The original artwork is unchanged.

The loading animation is adapted from `statedge-loader.js` in
`src/components/StatEdgeLoader.tsx` and `src/styles/loader.css`: its rings, logo reveal,
glint and wordmark are retained. React controls its lifetime; the demo's forced
3.4-second wait and Google Fonts request are omitted. Sora is self-hosted under
`public/fonts` with its SIL Open Font License. Reduced motion shows a static mark.
